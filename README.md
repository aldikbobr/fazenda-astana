# ФАЗЕНДА — концепт сайта

Концепт-сайт комплекса саун на берёзовых дровах **«Фазенда»** (Астана, ул. 150 лет Абая, 10; круглосуточно).

- Сайт: https://fazenda-astana.vercel.app
- Закрыт от поисковиков (`noindex, nofollow`), в подвале помечен как концепт.

## Что внутри
- Прелоадер с пламенем, плавный скролл (Lenis), сцены GSAP ScrollTrigger.
- Пар и угольки над фото на первом экране (canvas), «термометр» прокрутки на десктопе.
- Каталог 14 саун с фильтрами (гостей, бассейн, хаммам, караоке, бильярд) и View Transitions; кнопка «Забронировать» подставляет сауну в форму.
- Горизонтальная сцена «Шесть шагов до перезагрузки», отзывы «стопкой» (sticky stack), форма брони → WhatsApp.
